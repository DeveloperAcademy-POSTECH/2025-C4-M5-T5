# Yut 게임 기능 보완 내역

**상태: 검증 대기 · 갱신: 2026-11-11**

Yut에 반영한 게임 규칙·입력·통신·AR 준비 기능 17개를 정리했다. 아래 표는 개선 전 문제와 보완 내용을 구분하며, 실기기 검증 완료를 뜻하지 않는다. 현재 구현·검증·남은 확인 항목은 [원본 개선 QA](yut-original-refactor.md)에서 추적한다. 평면 갱신 제어·충돌 캐시는 이후 [AR 발열 QA](../ar/ar-overheating.md)에서 별도로 반영했다.

## 게임 조작·규칙

| ID | 항목 | 개선 전 문제 | 보완 내용 |
| --- | --- | --- | --- |
| 01 | 말 재선택·선택 취소 | 목적지 단계에서 말 선택을 교체하지 않고 취소 버튼도 없음 | 목적지 단계에서 말 변경을 허용하는 상태 로직과 ‘말 다시 선택’ 버튼이 있음. 직접 탭 재선택까지 연결 |
| 02 | 업기 선택창 반복·닫기 | 한 번 닫은 `showModal`을 다시 켜는 경로가 없고, 바깥 탭으로 닫아도 미결 단계가 남음 | 게임 단계로 표시하며 업기/따로 가기를 결정해야 진행 |
| 03 | 분기 후 선택 경로 유지 | 후보의 경로 번호를 버리고 칸 이름만 전달. 이동 시 `routeIndex` 갱신 없음 | 목적지의 경로·인덱스를 말 위치에 저장 |
| 04 | 빽도 이동 이력 | 실제 지나온 경로 이력 없이 현재 경로의 칸 이름으로 계산 | 통과 위치 이력을 저장하고 역으로 이동 |
| 05 | 출발·도착 칸 구분 | `_6_6`을 판 밖 대기와 한 바퀴 후 도착에 사용하고 `firstIndex`로 탐색 | 판 밖·진행·완주를 구분하고 진행 중에는 경로 인덱스 사용 |
| 06 | 업힌 말의 그룹 이동 | 업기는 시각적 재배치 중심. 선택은 엔티티 부모·자식 관계를 따르지만 재배치는 타일 기준이라 불일치 여지 | `groupID`로 같은 그룹 이동·완주·잡힌 뒤 초기화 관리 |
| 07 | 낙 후 재던지기 | 결과에 관계없이 말 선택 단계로 이동 | 낙은 같은 플레이어의 던지기 단계로 복귀 |
| 08 | 움직일 말 없는 빽도 | 말 선택에 남으며 새 말 버튼도 단순 판 밖 말 유무로 표시 | 이동 후보가 없으면 다음 차례로 진행 |
| 09 | 완주·승리 확정 | `gameEnded`를 반환해도 완주 상태 반영·종료 처리가 연결되지 않음 | 말 완주 상태, 두 말 완주 시 승자 확정, 승리 화면 연결 |
| 10 | 승리 화면의 종료·재경기 | 기본 승자 ‘세나’, 별도로 만든 내비게이션을 조작하고 재경기 버튼은 TODO | 실제 승자 표시, 공유 앱을 통한 퇴장·새 판 생성·기기 간 재경기 요청 |

근거: 원본 [규칙](../../../Yut/Yut/Sources/Utility/Managers/AR/GameManager.swift), [현재 게임 조정](../../../Yut/Yut/Sources/Utility/Managers/Game/GameSessionController.swift), [입력](../../../Yut/Yut/Sources/Utility/Managers/AR/GestureHandler.swift), [말 배치](../../../Yut/Yut/Sources/Utility/Managers/AR/PieceManager.swift).

**01의 적용 범위:** 상태 로직과 취소 버튼뿐 아니라 ‘A 말 → B 말 직접 탭’으로 선택을 바꾸는 경로까지 연결했다.

## 통신·복구·준비

13번의 상시 나가기 X 버튼은 이후 사용자 요청으로 Yut에서 제거했다. 오류 안내의 퇴장·재시도와 승리 화면 종료는 유지한다. [후속 기록](yut-original-refactor.md#플레이-화면-x-버튼-제거) 참고.

| ID | 항목 | 개선 전 문제 | 보완 내용 |
| --- | --- | --- | --- |
| 11 | 실제 게임 상태 공유·조작 권한 | 로비는 보완했으나 게임 중에는 로컬 상태를 직접 변경. 기존 공유 데이터는 이름·단계·결과뿐이고 현재 로비 수신기로 처리되지 않음 | 호스트가 명령을 검증·확정하고 말 상태 전체를 공유. 소유 기기·게임 ID·버전으로 다른 차례·중복·오래된 요청 차단 |
| 12 | 기기 간 공유 말판 | 협업 데이터의 SDK 출력 콜백·수신 적용·공유 공간 맵 경로가 연결되지 않음 | 공간 맵·앵커 ID·배율 공유와 협업 데이터 송수신·적용 연결. 실기기 정렬 품질은 별도 검증 대상 |
| 13 | 게임 중 나가기·AR 오류 재시도 | 플레이 화면에 나가기·AR 재시도 경로 없음. 로비 연결 오류 알림과는 별개 | 나가기 확인, 오류 안내, AR 재시도 연결 |
| 14 | 센서 미지원·실패 대체 입력 | 모션 센서가 없으면 감지 함수에서 반환, 버튼을 숨긴 모으기 상태가 남을 수 있음 | 센서 미지원·실패 시 수동 던지기 버튼 제공 |
| 15 | 백그라운드·AR 중단 복구 | 화면 제거 때 카메라 중단은 추가됐지만 백그라운드·인터럽트별 센서/작업 중단·재정렬 연결 부족 | 중단 시 자원 정리, 복귀 시 재정렬 후 단계 재개, 이전 작업 결과 차단 |
| 16 | 자원 준비 완료와 화면 진행 | 로딩 명령을 보낸 뒤 실제 완료와 관계없이 3초 후 스캔으로 전환 | 모델·충돌 형상 준비를 기다린 뒤 진행하고 오류·재시도 제공 |
| 17 | 배치 후 인식 영역 색 관리 | 기존 평면 재질만 투명색으로 변경. 이후 새로 발견한 평면의 표시를 막는 상태 없음 | 그리기 컴포넌트를 제거하고 이후 갱신에도 숨김 상태 유지, 충돌은 보존 |

## 범위·검증·우선순위

- 44pt 터치 보정·중첩 메시 탐색과 로비 명단·시작 신호 등은 이미 `Yut`에 보완됐으므로 미구현 목록에서 제외했다.
- 최초 분석에서는 테스트를 재실행하지 않았다. 후속 이식은 회귀 53개·UI 3개·빌드 2종으로 검증했다. 실제 두 기기 공유·복구와 iPhone 15 Pro 사용성은 검증 대기다.
- 로컬 RealityKit 리소스 조회에서 `Board.usdz`의 `end`·`_6_6` 엔티티 존재는 확인했다. 이 조회가 완주 UI의 실기기 검증을 뜻하지는 않는다.
- 01~10의 규칙·선택·종료와 11~17의 통신·준비·복구 경로를 반영했다. 다음은 실제 두 기기의 공유 말판·차례·중단/복귀와 원본 물리 체감 검증이다.
- 윷 투사·반발·판정 타이밍의 선호와 성능 우열은 이 목록으로 판단하지 않는다. 평면 생성 큐·충돌 캐시 등은 실행 순서와 실제 사물 충돌을 보존할 수 있는지 측정 후 선별한다.
