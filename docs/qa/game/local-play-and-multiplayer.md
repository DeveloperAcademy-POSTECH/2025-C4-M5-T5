# 한 기기 플레이·멀티 방 분리

**상태: 검증 대기 · 우선순위: 중간 · 갱신: 2026-11-13**

기존 방에서 같은 기기의 플레이어를 추가하던 기능을 별도의 한 기기 플레이로 분리했다. 멀티플레이 방은 기기당 한 명만 참가한다.

## 반영 내용

| 영역 | 현재 동작 |
| --- | --- |
| 로비 | ‘한 기기로 플레이’·‘방 만들기’·‘방 참여하기’로 진입 분리 |
| 대기실 UI | 기존 중앙 헤더·2열 격자·289pt 카드·하단 시작 버튼을 `WaitingRoomLayout`으로 공유. 한 기기도 PlayerCard·AddPlayerCard를 그대로 사용하며 별도 색상 카드·안내 섹션·삭제 배지를 두지 않음 |
| 한 기기 구성 | 기본 슬롯 1·2 선택. 빈 슬롯의 `+`로 추가, 선택된 카드 재탭으로 삭제. 2~4명일 때 시작 가능 |
| 이름·색상 | ‘플레이어 1~4’와 기존 말 색상을 슬롯 번호에 고정. 1번을 빼도 2·3·4번을 다시 번호 매기지 않음 |
| 로컬 세션 | 시작 시 광고·탐색·MCSession을 정리하고 외부 초대·명단 메시지를 차단. 모든 플레이어의 조작 기기는 같은 기기 |
| 멀티 방 | 닉네임과 기존 4칸 배치 유지. 빈 카드에는 조작 없는 참가 대기 아이콘을 표시. 추가 버튼·입력 모달 제거, 이전 추가 인원 메시지 무시·중복 거부 |
| AR 현황판 | 말 아이콘을 20pt에서 40pt로 확대. 공용 `PieceIcon`에서 원본 투명 여백을 보정하고 이름과 간격·정렬 조정 |

새 독립 화면은 `LocalPlayView`–`LocalPlayViewModel`, 하위 슬롯은 `Views/Lobby/WaitingRoom/SubViews`에 둔다. 이미지 표시만 DesignSystem에 두고, 게임 규칙·말 2개·배치 자동 시작·기존 재경기 경로를 재사용한다. 윷 투사·모으기·물리·리소스는 변경하지 않았다.

## 검증

- **단위·통합 142개 / 18개 suite 통과:** 슬롯 토글·인원 제한·실패 재시도·중복 시작 차단, 로컬 슬롯 이름·색상·동일 기기 권한, 외부 참가 차단, 종료 후 멀티 방 전환, 멀티의 중복 인원 거부를 포함한다. 기존 승리·재경기·통신·AR 회귀도 통과했다.
- **UI 3개 통과:** 슬롯 추가·삭제·홈 복귀 후 기본값 복원, 멀티 방의 추가 버튼 부재·재생성, 한 기기 플레이 → 배치 → 자동 시작 → 모으기 → 수동 던지기 → 결과 확인.
- **iOS 기기용 빌드 성공:** 새 Swift 컴파일 오류·경고 없음. 기존 AppIntents 메타데이터 안내만 발생했다.
- **초기 렌더 검증 6개 통과:** 별도 구성 화면의 라이트·다크와 확대된 AR 말 아이콘을 확인했다. 사용자의 기존 틀 유지 요청에 따라 별도 구성 화면은 아래 후속 작업에서 대체했다.
- 자동 실행은 iOS 18.3.1 시뮬레이터용 임시 프로젝트를 사용했으며 저장소 배포 대상 18.5는 유지했다. 실제 두 기기 통신·실물 카메라에서의 아이콘 가독성은 **검증 대기**다.

결과: `/tmp/yut-local-first.xcresult`, 빌드: `/tmp/yut-local-device.log`, 후속 라이트·다크 렌더: `/tmp/yut-local-layout-verified.xcresult`.

## 작업 이력·다음 확인

- **2026-11-13:** 플레이 방식 분리, 자동 이름·슬롯 토글, 말 아이콘 확대. 테스트·빌드 통과. 실기기 QA는 사용자 요청에 따라 수행하지 않았다.
- **2026-11-13 / UI 복원:** 별도로 만든 색상 슬롯·상단 안내·스크롤 화면을 제거하고 원래 대기실 레이아웃과 프로필/추가 카드를 재사용했다. 두 화면은 표시 데이터·카드 액션만 다르게 전달한다. 인원별 ‘둘이서/셋이서/넷이서 윷놀이 시작하기’ 문구도 복원했다.
- **복원 검증:** 관련 단위·렌더 15개 / 3개 suite, 로컬 슬롯·멀티 로비·AR UI 3개와 기기 빌드 통과. 결과 `/tmp/yut-room-ui-restore.xcresult`, `/tmp/yut-room-ui-device.log`. 기본 크기·여백·프로필 이미지는 기존 컴포넌트를 그대로 사용한다. 실제 기기 확인은 대기다.
- 다음 확인: 실제 멀티 방의 기기별 참가, 2~4명 로컬 플레이의 차례·재경기, 작은 화면·실제 카메라 배경에서 아이콘 가독성.

- **2026-11-13 / 애니메이션 제거:** 한 기기 구성 화면의 트랜잭션에서 애니메이션을 비활성화해 슬롯 추가·삭제와 시작 버튼 상태가 즉시 바뀌도록 했다. 공유 대기실 컴포넌트와 멀티 화면은 유지했다. 시뮬레이터 빌드·기존 LocalPlayViewModel 테스트·슬롯 추가/삭제 UI 테스트 통과 (`/tmp/yut-local-no-animation.xcresult`). 실기기 전환 감각은 검증 대기다.
- **2026-11-13 / 카드 정렬·눌림 효과:** 프로필 카드와 빈 카드의 상단 여백·이름 영역 차이를 확인했다. 공통 `PlayerSlotCard`에서 같은 원 크기·여백·이름 공간을 사용하도록 수정해 로컬·멀티 모두 정렬했다. 로컬 카드의 기본 `.plain` 버튼 스타일을 눌림에 따른 투명도 변경이 없는 스타일로 대체했다. 이전 애니메이션 비활성화만으로는 기본 눌림 효과를 제거하지 못했다. 시뮬레이터 빌드·렌더 테스트 6개·슬롯 UI 테스트 1개 통과, 렌더 이미지에서 말과 `+` 원 정렬 확인 (`/tmp/yut-slot-alignment.xcresult`). 실기기 터치 감각은 검증 대기다.
