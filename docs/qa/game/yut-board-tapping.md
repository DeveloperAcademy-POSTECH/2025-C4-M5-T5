# 말·이동 지점 터치 사용성

**상태: 검증 대기 · 우선순위: 높음 · 갱신: 2026-11-13**

말과 이동 지점을 선택하기 어렵다는 제보가 있었다. 기존 터치 처리는 3D 충돌 엔티티에 의존했다. **원본 외형·물리를 유지하면서 터치 시점의 화면 좌표 보정을 추가했다.** 실제 iPhone 15 Pro에서 선택 성공률은 아직 측정하지 않았다.

## 확인한 차이와 적용

| 항목 | 기존 원본 | 적용 후 |
| --- | --- | --- |
| 작은 말·타일을 빗나간 탭 | 3D 엔티티를 찾지 못하면 반환 | 유효한 3D 선택이 없을 때 중심 기준 44×44pt 안의 후보를 확인 |
| 윷판 충돌체가 먼저 잡힌 경우 | 말 UUID·타일 이름을 찾지 못하면 반환 | 현재 차례의 말 또는 허용된 이동 지점의 화면 좌표로 보완 |
| 깊이 중첩된 말 메시 | 엔티티와 바로 위 부모까지만 UUID 확인 | 실제 말 UUID가 있는 조상까지 확인 |
| 타일 내부 메시 이름 | 처음 만난 `_` 이름을 타일로 취급 | 현재 허용된 목적지 이름이 있는 조상까지 확인 |
| 보정 영역 중복 | 별도 기준 없음 | 화면 중심이 가까운 대상 → 같은 거리면 앞쪽 깊이 → 같으면 고정 식별자 순 |
| 계산 시점 | 탭 시 3D 조회 | 탭 시 3D 조회와 필요한 화면 투영만 실행. 상시 타이머·프레임 작업 추가 없음 |

**선택한 말이 이동 가능한 칸의 내 말이나 지점을 탭하면 즉시 자동으로 업는다.** 이동할 수 없는 다른 말은 선택을 바꾸지 않으며, 재선택은 ‘말 다시 선택’ 이후에만 가능하다. 정확히 맞은 유효 3D 선택을 우선하고, 화면 보정도 현재 단계에서 허용된 말·목적지만 후보에 넣는다. 보정 후보는 카메라 앞·화면 안의 활성 엔티티로 제한한다. 상대 말을 직접 누른 입력은 주변 내 말 선택으로 바꾸지 않는다. 타일 위 말이 타일의 보정 중심을 옮기지 않도록 타일 자체 메시의 중심을 사용한다.

화면의 투명 버튼을 그대로 복사하지 않은 이유는 원본의 제스처·화면 계층을 유지하고 상시 좌표 갱신 비용을 피하기 위해서다. 44pt 보정 범위가 적용되는 효과는 가져오되, 기존 3D 판정과 함께 사용한다.

관련 코드: [터치 해석](../../../Yut/Yut/Sources/Utility/Managers/AR/BoardTapResolver.swift), [제스처 연결](../../../Yut/Yut/Sources/Utility/Managers/AR/GestureHandler.swift). 선택·이동은 호스트가 확정한 GameState에 연결했다. 말 크기·0.5초 이동 연출은 유지하고, 이동 완료 뒤 재배치하도록 지연 콜백을 정리했다. 충돌 형상·윷 투사·정지 판정은 이번 터치 개선 대상이 아니다.

| 원본 물리·연출·리소스 보존 | 이번 규칙 이식은 여러 연결 파일을 변경했다. YutModel·모으기 View·리소스 136개 해시와 원본 투사 핵심 구간 일치. [상세 근거](../migration/yut-original-refactor.md#원본-물리-보존-근거) |

테스트: [좌표·식별자 해석](../../../Yut/YutTests/Utility/AR/BoardTapResolverTests.swift), [원본 이동·보정 연결](../../../Yut/YutTests/Utility/AR/BoardTapFlowTests.swift). 합성 장면 테스트는 실제 카메라 추적·가림·손가락 사용성 측정과 구분한다. 기존 GameManager·ARView 확장·리소스 관련 경고와 시뮬레이터 햅틱 초기화 로그는 별개다.

현재 결과는 `/tmp/yut-hybrid-verified-unit.xcresult`에 있다. 최초 23개 검증 결과는 `/tmp/yut-tap-final-tests.xcresult`다. 실행은 임시 프로젝트에서 배포 대상만 18.3으로 낮춘 iOS 18.3.1 시뮬레이터이며, 저장소 기본 배포 대상 iOS 18.5는 유지했다. 최초 터치 보완은 단위·통합 테스트로 검증했다. 후속 규칙 이식에서는 로비와 AR 진입·투사·퇴장 UI 3개도 통과했다. 직접 말 재선택의 손가락 사용성은 실기기 검증 대기다.

## 남은 실기기 확인

최신 자동 검증에서는 말 선택 시 보유 결과 전체의 목적지를 강조·탭 대상으로 제공하고, 첫 칸에서 빽도로 돌아온 말이 출발점에 보이는지 확인했다. 서로 다른 결과가 같은 목적지로 이어질 때만 결과를 확인한다. 상세 규칙·검증은 [전체 이동 후보·출발점 빽도](turn-results-and-piece-status.md#전체-이동-후보출발점-빽도--2026-11-13)를 따른다.

1. iPhone 15 Pro에서 가까운/먼 말판, 비스듬한 시점, 카메라를 움직인 직후에 말·목적지 중심과 가장자리를 눌러 확인한다.
2. 인접·업힌 말과 여러 이동 후보가 겹칠 때 의도한 대상이 선택되는지 확인한다. 동일 위치의 별개 말은 고정 식별자 순 선택이 적절한지 본다.
3. 실제 사물에 가려진 대상, 화면 가장자리의 대상, UI 버튼·모달이 있는 영역에서 오선택이 없는지 확인한다.
4. 보정 전후 같은 조건의 성공 횟수·오선택을 기록한다. 체감 확인 전에는 선택 성공률 개선 수치를 확정하지 않는다.
