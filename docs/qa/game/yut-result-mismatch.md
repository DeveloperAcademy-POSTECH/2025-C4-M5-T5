# 보이는 윷의 면과 결과 불일치

**상태: 검증 대기 · 우선순위: 높음 · 갱신: 2026-11-11**

같은 월드 자세인데 부모 앵커 회전에 따라 결과가 달라지는 원본 판정 오류를 재현하고 **면 방향 계산만 수정했다.** 빌드 2종·회귀 57개가 통과했다. iPhone 15 Pro의 실제 보이는 면 확인은 대기다.

## 원인과 수정

| 항목 | 수정 전 | 수정 후 |
| --- | --- | --- |
| 회전 기준 | 부모 앵커 기준 `entity.transform.rotation` | `entity.orientation(relativeTo: nil)`로 부모·카메라 앵커 회전까지 포함한 월드 방향 사용 |
| 위쪽 기준 | X축 `(1, 0, 0)` 고정 | 월드 +Y `(0, 1, 0)`와 비교 |
| 모델 면 해석 | 로컬 +Y를 잘못된 좌표 기준에서 비교 | 실제 모델의 **둥근 면이 로컬 +Y**인 점을 사용해, 월드 위쪽 내적 `> 0`이면 둥근 면이 위라고 판정 |
| 도·개·걸·윷·모·빽도 | 둥근 면 개수·빽도 이름으로 계산 | 개수·빽도 계산은 유지. 평평한 면 0개=모, 1개=도/빽도, 2개=개, 3개=걸, 4개=윷으로 확인 |

실제 네 USDZ의 평평한 쪽 메시 법선은 대체로 로컬 -Y이며 빽도 모델 이름은 `Yut_4_back`이다. **변경한 앱 코드는 YutManager의 면 판정 함수뿐이다.** 윷 생성·질량·마찰·반발·투사 속도·충돌 형상·정지 조건·확인 간격·결과 표시 시간은 작업 직전 파일과 일치한다.

근거: [면 판정](../../../Yut/Yut/Sources/Utility/Managers/AR/YutManager.swift#L293), [정지 조건](../../../Yut/Yut/Sources/Models/AR/YutModel.swift). Apple은 [transform이 부모 기준](https://developer.apple.com/documentation/realitykit/hastransform/transform)이며 [AR 월드 위쪽이 +Y](https://developer.apple.com/documentation/arkit/understanding-world-tracking)라고 설명한다.

## 재현·검증

좌표 재현은 실제 낙하 실험과 구분한다. 윷의 월드 자세를 동일하게 고정하고 부모 회전만 바꿨다.

| 윷 상태 | 부모 Z 회전 | 수정 전 | 수정 후 |
| --- | --- | --- | --- |
| 네 둥근 면이 위 — 기대 모 | +90도 | 윷 | **모** |
| 같은 상태 | -90도 | 모 | **모** |

| 검증 | 결과 |
| --- | --- |
| 버그 재현 테스트 먼저 실행 | 수정 전 새 면 판정 테스트 실패 확인 |
| 면 조합·앵커 회전 | 16가지 면 조합 × 부모 회전 6종 통과. 중첩된 조상 회전·빽도 포함 |
| 기울기·방향 | 기울어진 윷의 월드 방위 4종·동일 회전을 나타내는 쿼터니언 부호 반전에서도 빽도 유지 |
| 실제 리소스 | 네 USDZ를 로드해 부모 회전이 있는 상태의 모·빽도·윷 통과 |
| 전체 단위·통합 회귀 | **57개 / 9개 suite 통과**, 실패·건너뜀 없음 |
| iOS / iOS Simulator 빌드 | 두 대상 성공. 변경 코드의 새 Swift 컴파일 오류·경고 없음 |
| 범위 보존 | 면 판정 외 앱 코드·리소스 전부 작업 직전 SHA-256 일치. 투사·정지·결과 개수/빽도 계산 구간도 직접 비교 |
| 실제 iPhone 15 Pro | **검증 대기** |

테스트: [YutFaceJudgmentTests](../../../Yut/YutTests/Utility/AR/YutFaceJudgmentTests.swift). 결과: `/tmp/yut-face-red-suite.xcresult`, `/tmp/yut-face-green-tests.xcresult`. 빌드: `/tmp/yut-face-device-build.log`, `/tmp/yut-face-simulator-build.log`. 범위 대조: `/tmp/yut-face-before-sha.json`, `/tmp/yut-face-scope-checks.json`.

실행은 iOS 18.3.1 시뮬레이터 / SDK 27.2이며 테스트용 임시 프로젝트만 배포 대상을 18.3으로 바꿨다. 저장소 기본값 iOS 18.5는 유지했다. UI·통신 경로를 바꾸지 않아 UI 테스트는 재실행하지 않았다.

## 남은 확인

- iPhone 15 Pro에서 카메라 방향을 바꿔 던지고 최종 면·도/개/걸/윷/모·빽도를 비교한다. 관찰 기기의 최종 표시도 확인한다.
- **결과 확정 시점은 사용자 요청 범위 밖으로 유지했다.** 선속도·각속도 0.2 미만을 한 번 확인하면 확정하고 결과 표시 중에도 물리는 계속된다. 이후 윷이 더 굴러 면이 달라지는 가능성은 별도 검증 대상이다.
- 옆으로 세워진 윷의 별도 처리나 600ms 안정 조건도 추가하지 않았다. 관찰 기기의 100ms 전송·보간 없는 표시 방식도 유지했다.

기존 검증은 원본 판정식과의 일치에 치우쳐 월드 자세별 정답 검증이 부족했다. 이번 회귀는 실제 위를 향하는 면을 고정한 뒤 결과가 부모 회전과 무관하게 유지되는지 확인한다.
