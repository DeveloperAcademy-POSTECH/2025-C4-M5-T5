# 추가 던지기·보유 결과·말 상태 QA

## 문제와 확인한 동작

기존에는 결과 하나를 `latestResult`에 저장하고 윷·모를 이동에 사용한 뒤 추가 던지기를 제공했다. 여러 결과를 보유하거나 선택하는 기능은 없었다. 말은 이미 플레이어별 2개이며 `.home`·`.onBoard`·`.finished`로 대기·진행·완주를 구분했다. 이 내용은 코드 확인 결과다.

## 현황판·결과 선택·하단 패널 조정 — 2026-11-13

## 말 선택·완주·하단 조작 개선 — 2026-11-13

이 절은 해당 단계의 작업 기록이다. 업기 선택창과 결과 위치는 아래 후속 작업에서 변경했다.

| 영역 | 최종 동작 |
| --- | --- |
| 현황판 | 플레이어 색상을 카드 배경에 적용. 글자·활성 점은 대비색, 비활성 점은 약한 색으로 표시 |
