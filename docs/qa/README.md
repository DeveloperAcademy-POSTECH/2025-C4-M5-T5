## 게임 기능 보완

[원본 기준 이식·보존 근거](migration/yut-original-refactor.md)와 [보완한 기능 17개](migration/yut-feature-gaps.md)는 Yut의 기능 보완·검증 범위를 담는다. 전체 규칙·공유 공간·중단 복구는 검증 대기이며, 후속 변경은 위 개별 QA를 따른다.

## 최근 작업

- **2026-11-12 / 문서 본문 관리:** 약관·방침 본문은 Resources/Legal에서 관리하도록 중복 문서를 제거했다. 앱 리소스 보존·내부 링크 확인. [기록](ui/settings-and-legal.md).
- **2026-11-12 / 문서 현행화:** 현재 Yut의 구현·보완 내역 중심으로 설명을 정리하고, 삭제된 소스·보관 문서의 참조를 제거했다. 앱 코드 변경 없음. [기록](structure/directory-structure-review.md#작업-이력검증).
- **2026-11-12 / 개발 문서 정리:** 개발 기준 3개를 guides에 모으고 기능·출시 섹션을 제거했다. AGENTS.md와 관련 문서 링크를 갱신했다. [기록](structure/directory-structure-review.md#작업-이력검증).

이전 날짜별 작업은 각 QA 상세 문서에서 확인한다. 문서 작성 기준은 [작성·갱신 규칙](../README.md#작성갱신-규칙)을 따른다.
