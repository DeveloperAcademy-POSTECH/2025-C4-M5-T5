## 게임 기능 보완

[원본 기준 이식·보존 근거](migration/yut-original-refactor.md)와 [보완한 기능 17개](migration/yut-feature-gaps.md)는 YUT의 기능 보완·검증 범위를 담는다. 전체 규칙·공유 공간·중단 복구는 검증 대기이며, 후속 변경은 위 개별 QA를 따른다.

## 최근 작업

- **2026-11-13 / 역할별 화면 그룹** · 로비·게임·설정을 관련 화면끼리 묶고 각 그룹 안으로 SubViews를 이동했다. ViewModel 11쌍 대응·구현 내용 보존·문서 링크를 확인했다. 빌드 2종·단위 143개·UI 5개 통과. [검증 기록](structure/directory-structure-review.md#역할별-화면-그룹-적용--2026-11-13).

- **2026-11-13 / 카드 정렬·반짝임** · 프로필과 빈 슬롯의 원 위치를 공통 카드 틀로 맞추고, 로컬 카드의 눌림 투명도 효과를 제거했다. 빌드·렌더 6개·UI 1개 통과. [검증 기록](game/local-play-and-multiplayer.md).

- **2026-11-13 / 로컬 구성 애니메이션** · 한 기기 플레이의 카드·시작 버튼 상태 변경 애니메이션을 비활성화했다. 시뮬레이터 빌드·관련 단위/UI 테스트 통과. [검증 기록](game/local-play-and-multiplayer.md).

- **2026-11-13 / 플레이 방식 분리** · 기능 분리는 유지하고, 별도로 만든 한 기기 화면을 기존 대기실 레이아웃·카드 재사용으로 수정했다. 관련 15개·UI 3개·기기 빌드 통과. [검증 기록](game/local-play-and-multiplayer.md).
- **2026-11-13 / 배치·모으기** · 배치 후 자동 시작과 모으기 첫 표시의 화면 생성 작업 축소를 반영했다. 138개·기기 빌드·UI 재검증 통과. 최초 UI 크래시와 미측정 성능은 [기록](game/yut-gathering-hitch.md)에 구분했다.
- **2026-11-13 / 게임 조작·말 상태** · 말 선택 시 전체 목적지 표시·결과 자동 소비, 빽도 출발점 표시와 재차 빽도 완주를 적용했다. 전체 134개·AR UI·iOS 빌드 통과. [기록](game/turn-results-and-piece-status.md#전체-이동-후보출발점-빽도--2026-11-13).
- **2026-11-13 / 제작자 화면** · 상단 배치·사람 아이콘 제거를 적용하고 iOS 빌드·설정 UI를 확인했다. [기록](ui/settings-and-legal.md).
- **2026-11-13 / 약관·문의** · 시행일 확정·오픈채팅 연결·문서 문의처를 반영했다. [기록](ui/settings-and-legal.md).

이전 날짜별 작업은 각 QA 상세 문서에서 확인한다. 문서 작성 기준은 [작성·갱신 규칙](../README.md#작성갱신-규칙)을 따른다.
