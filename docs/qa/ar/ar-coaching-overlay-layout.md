# AR 화면 왼쪽의 검은 사각형·잘린 기본 안내

**상태: 수정 반영 · 실기기 검증 대기 · 우선순위: 중간 · 갱신: 2026-11-12**

사용자가 보낸 가로 화면에서 왼쪽에 어두운 사각형과 잘린 기기 그림·영문 안내가 보인다. **AR 기본 코칭 안내의 레이아웃 오류를 확인했으며, 사진의 검은 영역과의 연관성이 높다고 판단한다.** 실기기에서 해당 뷰를 숨기는 전후 비교는 아직 하지 않았다.

| 구분 | 확인한 내용 |
| --- | --- |
| 생성 경로 | ARCoordinator는 실기기에서 세션 시작 후 ARCoachingOverlayView를 자동 추가한다. 앱의 자체 스캔 게이지와 별도로 표시되며 활성화·종료에 맞춘 UI 조정은 없다 |
| 레이아웃 | addCoachig는 flexibleWidth/Height만 지정하고 초기 frame·부모에 고정하는 제약을 설정하지 않는다 |
| 진단 결과 | 현재 메서드로 생성했을 때 가로 ARView 1376×1032에 overlay frame은 0×0, 세로 1032×1376으로 바꾸면 0×344였다. 부모와 연결하는 제약은 0개였다. SDK 27.2 / iOS 18.3.1 시뮬레이터의 임시 진단 테스트 1개로 측정했다 |
| 판단 한계 | AR 코칭의 실제 카메라 안내·검은 배경은 실기기에서 비교하지 못했다. 위 결과는 뷰의 크기가 잘못된다는 근거이며 사진의 전체 픽셀을 재현한 결과는 아니다 |
| 후속 | 자체 스캔 안내와 기본 코칭의 중복 정책을 정한다. 이번에는 기본 코칭 제거를 선택했다. 기기 그림·영문·검은 사각형의 실기기 전후 비교는 사용자 QA 중단 요청으로 수행하지 않았다 |

위 표는 수정 전 분석이다. 이후 **기본 코칭의 자동 추가와 해당 코칭만 생성하던 ARView+Extension.swift를 제거**했다. 기존 자체 스캔 게이지·안내·방장 전용 배치 조작은 유지했다. AR 공간 인식·공유 맵·충돌면은 변경하지 않았다.

현재 코드: [AR 세션 시작](../../../Yut/Yut/Sources/Utility/Managers/AR/ARCoordinator.swift), [자체 스캔 UI](../../../Yut/Yut/Sources/Views/Game/SubViews/Play/PlacementControls.swift). 기본 코칭의 역할은 [Apple 문서](https://developer.apple.com/documentation/arkit/arcoachingoverlayview)를 참조했다.

진단 자료: `/tmp/yut-coaching-analysis.log`, `/tmp/yut-coaching-analysis.xcresult`. 분석 단계의 진단 프로젝트·테스트는 `/tmp/yut-coaching-analysis`에만 작성했다. 후속 수정 후 앱 소스에서 ARCoachingOverlayView 생성 경로가 없음을 확인했다. iOS 서명 빌드·전체 회귀 101개·로비/AR UI 3개 통과. 실기기에서 사진의 검은 영역 제거를 직접 확인하는 QA는 사용자 요청으로 중단했으며, 시뮬레이터는 실제 AR 코칭 화면 검증을 대신하지 않는다.
