# YUT 게임 진행과 규칙

**기준 프로젝트 `Yut/Yut.xcodeproj` · 갱신 2026-11-13**

YUT은 2~4명의 플레이어가 각각 말 2개로 진행하는 AR 윷놀이다. 자기 말 2개를 모두 완주한 플레이어가 승리한다.

## 플레이 방식

| 로비 메뉴 | 참가·조작 방식 |
| --- | --- |
| 한 기기로 플레이 | 닉네임 입력 없이 슬롯 1~4를 선택한다. 기본 1·2번 선택, 빈 슬롯의 `+`를 누르면 추가되고 선택된 카드를 다시 누르면 삭제된다. 2명 이상 선택해야 시작할 수 있다. 이름은 ‘플레이어 1, 2…’, 말 색상도 슬롯 번호에 고정된다. 모든 차례를 같은 기기에서 조작하며 방 광고·탐색·외부 참가 없이 진행한다 |
| 방 만들기·방 참여하기 | 닉네임을 입력하고 기기당 한 명씩 참가한다. 방 안에서 로컬 인원을 추가하는 버튼은 없다. 방장이 2~4명의 연결 완료를 확인한 뒤 게임을 시작한다 |

## 게임 시작과 AR 준비

1. 홈에서 플레이 방식을 선택하고 참가자를 구성한다. 멀티플레이는 대기실에서 다른 기기의 참가를 기다린다.
2. 한 기기 플레이의 시작 버튼 또는 멀티플레이 방장의 시작 버튼을 누르면 카메라가 켜진다. 주변 공간을 스캔하여 말판을 표시할 공간을 인식한다.
3. 한 기기 플레이는 해당 기기에서, 멀티플레이는 방장이 평면을 탭해 말판을 놓고 위치·크기·방향을 조절한 뒤 배치를 확정한다. 원격 참가자는 자기 공간 스캔을 마친 뒤 공유된 말판에 정렬한다.
4. 배치 확정·공유 준비가 성공하면 방장이 첫 차례를 자동으로 연다. 별도 시작 버튼 없이 첫 플레이어에게 ‘윷 모으기’를 표시한다. 참가자는 자기 공간 정렬까지 끝나야 조작할 수 있다. 배치 실패·취소·연결 종료 시에는 시작하지 않으며, 시작 상태 전송 실패는 기존 오류 안내의 재시도로 복구한다.

기기별 공간 인식·재정렬은 `BoardPlacementPhase`, 공유 게임 단계는 `MatchPhase`가 관리한다. 같은 공간에 말판을 표시하기 위한 AR 지도·기준점·협업 정보도 게임 연결을 통해 전달한다.

## 한 차례의 흐름

`윷 모으기 → 흔들기 또는 수동 던지기 → 결과 표시 → 추가 던지기 또는 말 이동 → 남은 결과 확인 → 다음 차례`

‘윷 모으기’를 누르면 기존 모으기 연출이 재생되고 흔들기 입력을 준비한다. 센서를 사용할 수 없는 경우에는 ‘윷 던지기’ 버튼을 제공한다. 실제 투사 기기가 물리 연산과 면·정지 판정을 수행하고, 다른 기기는 전달받은 윷 자세와 효과음을 재생한다.

모으기 이미지 뷰는 배치 후 미리 구성하고, 해당 단계에서만 표시·재생한다. 숨겨진 동안 재생 작업은 하지 않는다. 참가자는 방장이 확정한 모으기 상태를 받은 뒤 연출을 시작한다.

| 결과 | 이동 | 후속 진행 |
| --- | --- | --- |
| 도·개·걸 | 1·2·3칸 전진 | 결과를 보유하고 말 이동 단계로 전환 |
| 윷·모 | 4·5칸 전진 | 결과를 보유하고 말을 이동하기 전에 같은 사람이 한 번 더 던짐 |
| 빽도 | 실제 이동 이력에서 한 칸 후퇴 | 다른 보유 결과와 함께 이동 가능 여부 확인 |
| 낙 | 이동 없음 | 기존 보유 결과를 유지하고 같은 사람이 다시 던짐 |

윷·모가 연속으로 나오면 추가 던지기를 계속한다. 기존 판정·결과 표시 연출이 끝난 뒤 다음 던지기를 준비한다. 추가 던지기 중에는 보유 결과로 말을 움직일 수 없다.

예를 들어 윷 → 모 → 개가 나오면 보유 결과는 윷·모·개 세 건이다. 개를 먼저 쓰거나 윷·모를 먼저 쓸 수 있다. 같은 윷이 두 번 나오면 각각 독립된 결과로 한 번씩 사용한다.

## 보유 결과와 말 이동

- 하단 조작 영역 바로 위에는 보유 결과만 표시한다. 결과를 먼저 고르지 않고 말을 선택하면, 보유한 모든 결과로 갈 수 있는 목적지를 한꺼번에 강조한다.
- 대기 중인 말을 진출시키려면 ‘새 말 놓기’를 누른다. 판 위 말은 직접 탭하고, 강조된 이동 지점을 선택한다.
- 선택한 말이 이동 가능한 칸에 다른 내 말이 있으면, 그 말이나 칸을 탭해 자동으로 업는다. ‘따로 이동’이나 업기 선택창은 없다. 선택한 말을 바꾸려면 반드시 ‘말 다시 선택’을 누른 뒤 다시 고른다. 이동할 수 없는 다른 말을 눌러도 선택은 바뀌지 않는다.
- 목적지를 누르면 그 지점에 해당하는 결과 한 건을 자동으로 소비한다. 서로 다른 결과로 같은 지점에 갈 수 있을 때만 사용할 결과를 묻는다. 동일 결과가 여러 건이면 먼저 보유한 한 건을 소비한다. 확인창을 취소하면 말 선택과 결과를 유지한다.
- 자동 업기도 한 번의 확정 이동으로 처리한다. 같은 말에 여러 결과를 연속 사용하거나 두 말에 나누어 사용할 수 있다.
- 말 이동과 재배치 연출 동안 다음 입력을 잠근다. 일반 이동은 호스트의 0.8초 완료 전환 뒤 남은 결과 선택 또는 다음 차례로 이어진다.
- 남은 결과가 있으면 이동을 계속한다. 결과를 전부 사용하고 추가 던지기 기회가 없으면 다음 플레이어로 넘어간다.

윷·모의 추가 기회는 던진 시점에 처리한다. 보유한 윷·모를 나중에 이동에 사용했다고 추가 기회를 다시 부여하지 않는다.

## 잡기·업기·갈림길·빽도

| 상황 | 처리 |
| --- | --- |
| 상대 말이 있는 칸에 도착 | 해당 칸의 상대 말을 대기로 돌리고 그룹·이동 이력을 초기화 |
| 잡기 성공 | 사용한 결과만 소비하고 남은 결과를 유지한 채 추가 던지기 제공 |
| 업힌 상대 말 여러 개 잡기 | 각각 대기로 돌아가며, 한 번의 이동에서 잡기 보너스는 한 차례 제공 |
| 같은 편의 별도 말과 만남 | 자동으로 업어 같은 그룹·이동 이력으로 함께 이동. 별도 선택 없이 결과 하나만 소비 |
| 모서리·중앙 갈림길 | 기존 경로 계산이 제공하는 이동 지점 중 선택 |
| 빽도 | 실제로 지나온 이력을 따라 한 칸 되돌아감. 첫 칸에서는 판 위 출발점으로 돌아오며 말이 계속 보임 |
| 출발점에서 다시 빽도 | 빽도로 돌아온 출발점에서 다시 빽도를 사용하면 한 바퀴를 돌지 않아도 완주 가능. 전진 결과를 쓰면 첫 칸 방향으로 다시 진행 |
| 완주 | 전진으로 완주 목적지에 도달·초과하거나, 빽도로 돌아온 출발점에서 다시 빽도가 가능하면 ‘완주하기’를 표시. 서로 다른 결과가 겹치면 사용할 결과를 확인한 뒤 한 건 소비 |

잡기로 추가 던지기를 시작하면 기존 보유 결과에 새 결과를 합친다. 다시 윷·모가 나오면 연속 추가 던지기를 마친 뒤 이동을 재개한다.

빽도로 돌아온 출발점은 경로 인덱스 0의 판 위 위치다. 아직 진출하지 않은 대기 말과 구분하며, 같은 칸의 업기·잡기도 적용한다. 한 바퀴 돌아 출발점에 도착한 말은 경로 마지막 인덱스를 유지하므로, 그 말의 빽도는 기존 이동 이력을 따라 후퇴한다.

이동할 수 없는 빽도는 다른 결과를 먼저 사용한 뒤 다시 사용할 수 있다. 예를 들어 말이 모두 대기 중이고 윷·빽도를 보유했다면 윷으로 진출한 뒤 빽도를 사용한다. 모든 보유 결과가 이동 불가능하고 추가 던지기도 없으면 사용할 수 없는 결과를 정리하고 다음 차례로 넘어간다.

## 말 2개의 상태 표시

| 표시 | 실제 말 위치 | 바뀌는 상황 |
| --- | --- | --- |
| 진출 대기 | `PiecePosition.home` | 게임 시작, 잡힘 |
| 이동 중 | `PiecePosition.onBoard` | 판에 진출하여 진행 중 |
| 도착 완료 | `PiecePosition.finished` | 완주 |

AR 화면 상단의 현황판에는 닉네임·말 색상과 **대기 중인 말 / 완주한 말** 두 항목을 표시한다. 카드에는 그림자나 별도 컨테이너 배경을 두지 않는다. 카드 배경은 플레이어 색상, 글자와 활성 점은 그에 대응하는 대비색을 사용한다. 각 항목의 점 2개 중 해당 개수만큼 점등하고, 아래에 ‘0개’~‘2개’를 표시한다. 가로 스크롤로 다른 플레이어를 확인하고, 현재 차례는 이름 강조와 자동 스크롤로 구분한다.

집계는 확정된 `GameState.pieces`의 위치에서 계산하며 업힌 말도 각 한 개로 센다. 내부 대기·진행·완주 상태의 합은 항상 2다. 판 위에서 진행 중인 말은 실제 AR 말판에서 확인한다. 모으기·흔들기 준비에서는 해당 조작과 연출을 우선한다.

보유 결과는 말·목적지를 선택하는 단계에서만 하단 조작 영역 바로 위에 표시한다. 던지기·판정·추가 던지기·이동 연출 중에는 숨기되 결과 데이터는 유지한다. 별도 안내 문구·바깥 박스는 두지 않는다. 플레이어 색상으로 표시하는 읽기 전용 목록이며 선택 버튼·체크 아이콘을 두지 않는다. 서로 다른 결과가 같은 목적지에 겹칠 때의 확인창은 현재 조작 기기에만 표시한다.

하단에는 조작 버튼 하나를 표시하고 중복 안내 문구·외곽 패널을 두지 않는다. 던지기 준비에는 ‘윷 모으기’, 진출 가능한 대기 말이 있을 때는 ‘새 말 놓기’, 목적지 선택에는 ‘말 다시 선택’을 제공한다. 다른 기기의 차례·말 이동 중·흔들기 대기도 같은 ActionButton 크기로 안내한다. 실행 가능한 액션은 플레이어 색상과 터치 활성 상태, 상태 안내는 공통 비활성 색상과 터치 비활성 상태를 사용한다. 상태 변경의 페이드 없이 즉시 전환한다. 조작 권한은 기기에 등록된 플레이어의 `deviceID`로 판단한다.

완주 버튼은 현재 조작자의 목적지 선택 단계에서 출발점이 화면 안에 보일 때만 표시한다. 완주 가능 동안에만 최대 30Hz로 위치를 갱신하고 화면 경계·상하단 UI와 겹치지 않도록 배치를 제한한다. 기존 오른쪽 `end` 칸은 강조·탭 대상에서 제외하지만 충돌 형상과 물리 설정은 유지한다.

## 승리·재경기·중단

- 자기 말 2개가 모두 완주하면 남은 결과·보너스에 앞서 승리를 확정하고 기존 승리 화면을 표시한다.
- ‘다시 하기’ 요청은 방장이 새 게임으로 확정한다. 말 위치·보유 결과·선택 상태는 초기화한다.
- 게임을 마치고 방에서 나가면 연결을 정리하고 홈으로 돌아간다. 연결 종료로 진행 중인 게임이 정리될 때도 홈으로 복귀한다.
- AR 추적 실패나 앱 중단 시 진행 중인 투사를 취소할 수 있다. 이미 확정된 보유 결과는 유지하고, 취소된 투사의 늦은 판정은 적용하지 않는다.
- 공유 실패에는 기존 오류 안내·재시도 경로를 사용한다. 참가자 기기는 방장이 확정한 상태를 수신한 뒤 화면을 갱신한다.
